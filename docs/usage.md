# 使用指南

[← 返回 README](../README.md)

## 配置翻译接口

打开扩展的「设置」，从左侧预设添加接口，填写地址、API Key 和模型名称，点击「保存接口」，授权接口域名后测试连接。最多保存 20 个接口。

预设决定请求协议，名称可以修改，协议不能跨服务切换。扩展弹窗中的接口选择设置全局默认；Discord 每条消息还可单独选择接口重译，不影响其他消息。

### 模型列表

点击模型名称右侧的「拉取模型」，使用当前填写的地址和 API Key 获取可用模型，无需先填写模型或保存配置。

- 成功后显示下拉列表；选择模型后仍需点击「保存接口」。
- 当前模型不在返回列表中时保留原值，也可点击「手动填写」。
- 失败或返回空列表时显示原因，保留手动输入。
- 地址、密钥或接口变化后旧列表失效；列表只保留在当前设置页面中。

OpenAI 兼容服务读取 `/models`，Gemini 使用原生模型列表并过滤不支持文本生成的模型。该按钮不下载模型文件；本地服务只会列出已经安装的模型。

### DeepL

API 地址支持免费版、付费版和自定义。选择自定义才显示地址输入框，需填写支持 DeepL 原生协议的 API 根地址，通常到 `/v2`。

免费版为 `https://api-free.deepl.com/v2`，付费版为 `https://api.deepl.com/v2`。密钥应与版本匹配，可从 API Key 下方的链接打开 [DeepL 密钥管理页面](https://www.deepl.com/zh/your-account/keys)。DeepL 不需要模型名称，也不显示拉取模型按钮。

## 网页翻译

点击扩展图标 →「翻译此网页」，译文直接替换原位置的文字。滚动时继续翻译可见内容，包括正文、导航、按钮、可见悬停提示、输入框占位文字和原生 `title` 提示。点击「显示原文」恢复，也可在弹窗切换接口重译。

选中文字后右键 →「用译流翻译选中文字」，只替换选中部分。普通网页不添加双语段落或悬浮工具栏。

### 按域名自动翻译

在网页的扩展弹窗中开启「自动翻译此域名」，首次开启需授权相应域名。已打开的同域名网页立即生效，刷新、新标签页和重新打开时继续自动翻译，使用当前全局接口和目标语言。

也可在设置 →「普通网页」添加、编辑或取消常用网站。只填写域名，不含协议、路径或通配符。编辑时先授权新域名，再替换原设置；输入无效或拒绝授权会保留原域名。

| 规则             | 行为                                         |
| ---------------- | -------------------------------------------- |
| 完整主机名匹配   | `example.com` 与 `docs.example.com` 分开设置 |
| HTTP / HTTPS     | 同一主机名共用一条偏好                       |
| 点击「显示原文」 | 仅暂停当前页；刷新后按域名偏好继续           |
| 取消自动翻译     | 同域名已打开的页面恢复原文，并取消排队任务   |
| 撤销网站访问权限 | 清除对应自动翻译偏好                         |

最多记住 500 个域名。取消偏好不会主动撤销可能也用于翻译接口的域名权限，可在 Chrome 扩展管理页调整。

### 页面结构与恢复

翻译保留原元素、文字节点、链接地址和事件监听，不替换 HTML。输入值、下拉选项、编辑区、代码和 AWS 实例 ID、ARN、区域代码等资源标识保持原样；占位提示与输入值分开处理。

网站编辑内容、切换路由或用户恢复原文后，过期结果不会覆盖新内容。反复由网站重设的文字会暂停重试，下一次点击、键盘导航或聚焦后重新检查。恢复原文也会保留网站后续产生的新内容。

## Discord 阅读

进入网页版文字频道或私信后，每条外语消息下方出现翻译按钮。原文自动识别，短句不确定时以英语优先，翻译接口仍会判断原文语言。

- **单条翻译**：点击消息下方的「翻译」，完成后显示「识别为：英语 / 日语…」。切换该条消息的接口可重译。
- **批量翻译**：打开扩展弹窗，翻译可见消息或移除译文。
- **自动翻译**：开启弹窗中的「此频道自动翻译」，处理可见消息、新消息及编辑后的消息。其他频道默认关闭。
- **显示方式**：设置 →「Discord」选择「双语对照」或「仅显示译文」，立即更新已有译文。默认双语对照。

仅译文模式保留作者、时间和其他消息控件；移除译文或切回双语时恢复正文。频道开关按频道分别保存，切换服务器、私信和浏览器前进后退时同步；旧频道的请求不会覆盖新频道。

设置 →「Discord」列出已开启自动翻译的频道和私信，支持点击链接打开、逐个关闭或全部关闭。已打开的频道优先显示网页标题，其他频道显示服务器 / 频道 ID。接口报错时自动翻译会暂停，可在扩展弹窗查看原因。

## Discord 发送前翻译

在输入框写好草稿后，点击原生表情 / GIF 等工具前的「翻译成英语」。预览后选择「替换草稿」或「复制译文」，再自行发送消息。

右键翻译按钮可更换并记住发送语言，按钮随之变成「翻译成日语」等。菜单支持 Shift+F10、方向键、Enter 和 Escape；点击其他位置关闭菜单或预览。

也可从扩展弹窗展开「发送前翻译」，选择语言、翻译草稿，然后替换或复制。发送目标默认英语，与阅读目标语言分别保存；两个入口的选择保持同步。主频道和线程同时打开时，各按钮只操作自己的输入框。

草稿仅在主动点击翻译后读取并发送给所选接口，不自动发送 Discord 消息。预览期间修改草稿、频道、接口或发送语言会使旧结果失效；含提及、表情图片等特殊节点的草稿只允许预览和复制。不支持直接回填的编辑器会提示手动粘贴。

## 性能与缓存

OpenAI 兼容接口支持边生成边显示，按钮、链接和表格标签在完成后一次更新。重复内容复用会话缓存，Discord 手动翻译优先于排队中的自动任务。

自动队列串行执行，长段落按约 1400 字符分段，翻译超时为 90 秒。关闭自动翻译会取消待处理任务；已发出的请求可能继续完成，但失效结果不会显示。

缓存最多 200 条、约 100 万字符，不参与同步。后台 worker 休眠后可恢复，浏览器重启、扩展重新加载或在设置中清除缓存后清空。修改接口配置或密钥也会清空缓存。

## 兼容范围

支持 Chrome 120+，Discord 适用于 `discord.com`、`ptb.discord.com`、`canary.discord.com` 网页版。Chrome 内部页、商店页面、PDF、图片内文字、iframe、Shadow DOM 正文和 Discord 桌面客户端暂不支持。

网页按可见文字节点翻译，一个句子被多个元素切开时可能影响连贯性。Discord 大幅修改页面结构后可能需要适配更新。当前没有验证登录后的 Discord 或 AWS 控制台；已有验证见[验证记录](../VALIDATION.md)。
